Protocol diagnostics

Leave this off for normal use. The decoder has not been confirmed on hardware, so if a reading looks wrong or the link never reaches ready, probe mode connects, enumerates the GATT services and characteristics, subscribes to anything that notifies, and hex-dumps what arrives to the Status tab's log — without decoding it. See docs/PROTOCOL.md for what to look for.

Your unit's figure — 200 W on an Elite 10. Published as ups.realpower.nominal, and the 100% reference for ups.load.

Published as battery.runtime.low. LB is raised by this or the low-battery %, whichever comes first.

Clients connect with upsc bluetti@<ip>.

Login for upsmon

These gate LOGIN and PRIMARY — the commands upsmon uses to coordinate shutdown. Reading values stays anonymous, as it is on a normal NUT server, because upsc has no way to send credentials.

In upsmon.conf:
MONITOR bluetti@<ip> 1 upsmon <password> slave

From GitHub

Downloads the release straight from github.com over HTTPS. The image is not signed — anyone who can intercept that connection, or who controls the repository, controls what gets installed.
